# 被伤害后，怎么告诉别人

小学版｜6—11 岁

有人让你受伤或害怕，你不必知道这件事叫什么，也能求助。可以对信得过的大人说：“有人伤害我，请帮帮我。”如果危险正在发生，能安全做到时可以呼喊或示意求助，找能保护你的人。

说记得的部分就可以。说不清、不记得，或者想画出来，都可以。你不需要回去找那个人，也不需要再经历一次来证明。

你可以问正在负责帮你处理的大人：“接下来你会做什么？你会告诉谁？”不问也可以求助；遇到危险时先求救。

如果第一个大人没有认真帮你，找另一位信得过的老师或照护者。家里有人让你害怕时，可以找家庭以外的信得过的老师或照护者。你没有照片、录像或其他材料，也可以求助。

如果有人正在伤害你，身边没有能及时帮忙的大人，在中国大陆，能安全打电话时可以拨 110，告诉接线人员你知道的位置和眼前危险；没有手机时，尽量向附近能帮忙的人求助。

## 给支持孩子的大人

先倾听、保护及安排必要医疗，用孩子能理解的话解释接下来要做什么；不责备、不诱导细节、不反复要求复述，也不让孩子对质。依法报告并说明必要信息分享；当照护者可能施害时，需评估安全保护路线。
