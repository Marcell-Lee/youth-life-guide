# 家里没人听我说，我还能找谁

小学版｜6—11 岁

有件事想说，家里人却很忙，或者一开口就责备你。你仍然可以找人帮忙。

想一位让你感到信得过的大人，比如老师或其他照护者。你可以说：“我有件事想请你听。”你可以只说：“我现在需要有人陪我。”不用把所有事情一次讲完。

没有眼前危险或急需帮助时，如果他暂时没空，可以问什么时候能听。如果他嘲笑你、吓你，或者一直不回应，就换另一位信得过的大人。不是因为你讲得不够好，才没有得到帮助。

如果你想到伤害自己或别人，或觉得自己不安全，马上告诉能帮忙的信得过的大人，不必等改天。

如果你现在想结束自己的生命、担心自己或别人马上受到严重伤害，或者有人正在伤害你，不必等那位大人有空。

如果能安全离开，可以去能够得到帮助的安全地方；能安全使用电话时，在中国大陆，眼前人身威胁可以拨 110；有紧急医疗需要可以拨 120。

没有电话时，尽量在安全的情况下向附近能帮忙的人求助，请他们按情况帮忙拨打 110 或 120 求助；不要为了找电话回到危险处。

## 给支持你的大人

告诉孩子什么时候能听，并兑现。不能处理时，由成人联系能帮忙的人并跟进，不公开敏感细节，也不承诺绝对保密。让孩子按自己的节奏说，不要求反复讲述让他害怕的细节；涉及保护职责时，提前解释必要的信息分享边界。家庭不安全时，学校不能把先找家长作为唯一出口。
