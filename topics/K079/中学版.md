# 想兼职或参加实践，要先确认什么

中学版｜12—17 岁

你想挣钱或了解工作，有人说签个“体验协议”就能开工。先弄清楚活动性质、地点、任务和规定，不因名字叫实践就默认安全或合法。

**12—15 岁：**如果有人叫你到店里、工地或线上“试工”“兼职”，先不要答应，也不用靠工作来证明自己。在中国大陆，法律原则上禁止招用未满 16 周岁者，国家另有规定的除外；签“体验协议”、家长同意或对方保证安全，不会自动让普通招聘成为例外。请信得过的老师或其他能帮忙的大人，帮你向有关部门核对活动性质与规定。对方催促你保密、交证件或先付款，也先停下并求助。

学校按照国家有关规定组织、不影响人身安全和身心健康的教育实践劳动，法律对其有专门规定，与用人单位招工不能简单等同；做家务也不能仅凭“劳动”两字判断成被招用。活动叫“实践”不等于一定安全合法；不清楚或不舒服时，可以说：“我不明白这要做什么，请帮我弄清楚。”如果组织者或家人不安全、没有回应，可以找另一位信得过的老师或其他可信成人协助。

**16—17 岁：**仍受特殊保护。营业性娱乐场所、酒吧、互联网上网服务营业场所等不适宜未成年人活动的场所不得招用未成年人；不得安排未成年人从事过重、有毒、有害等危害身心健康的劳动或危险作业；具体岗位是否属于禁止范围，需要专业部门结合规定核查。请可信任的大人帮你核对单位、任务、工时、报酬和保护。对方不说清、要求交押金或借卡代收钱时，先停下并求助。

如果已经参加后受威胁、被扣证件、身体不舒服或拿不到报酬，可以请学校、可信任的大人及当地有关部门协助；不要独自争抢证件或对质。没有可靠家长时，可找学校或社区保护人员。

## 给支持孩子的大人

请相关专业部门核对实际法律关系、具体限制、例外和救济。未成年工的必要保护责任由单位依法承担，不能用“自愿”或“实习”字样免除；不能保证赔偿或自动认定劳动关系。
