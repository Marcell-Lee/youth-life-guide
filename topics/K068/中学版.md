# 求助时，我一定要准备证据吗

中学版｜12—17 岁

求助或投诉时，可以先讲自己在哪里、发生了什么、现在担心什么、需要什么帮助。不知道的直接说不知道；这些只是帮助对方理解的提示，不是求助资格表。

手边已有订单、消息或记录时，可告诉合适的接手者；不要为了补材料再见危险的人、进入账号或录下侵害。涉及私密影像，不要截图、下载或转发，也不要为了取证再次查看；请接手的可信任的大人向适当机构询问处理方式。先求助，由负责人员决定如何处理已有材料。

问对方负责什么、下一步怎样联系。没有手机可商量通过信得过的老师或约定地点反馈；家里不安全时先说出来。没有回应时请另一位可信任的大人协助继续反映。

如果正在遭受人身伤害或有人正要伤害你，先找能及时接手的人；没有成人能及时帮忙时，在中国大陆，能安全打电话可以拨 110 求助，不必等信息准备完整。没有电话时，能安全做到时，可以请附近的人帮忙报警，不要为了找电话进入危险处。

## 给支持孩子的大人

先判断安全和医疗需要，不因叙述遗漏否定孩子。避免反复询问侵害细节，说明保密边界及下一步，最小化信息分享；正式证据要求由专业程序确定。
