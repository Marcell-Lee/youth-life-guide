# 和朋友吵架后，一定要和好吗

小学版｜6—11 岁

你和朋友为了游戏吵起来，可以先停一下。愿意又安全的时候，再请大人帮助你们分别说说发生了什么，一起想下次怎么玩。

如果自己说了伤人的话，可以为那句话道歉；但不用为了和好把所有的错都说成是自己造成的。朋友暂时不想说，也不用逼他马上和好。

如果朋友把你不想让别人知道的事说了出去，你可能会难过。安全时，你可以说：“这件事我不想让更多人知道，请不要再说。”也可以请信得过的大人帮忙。信得过的大人可以和你一起想办法，但不能保证别人一定不再说。若事情涉及有人受伤或有危险，可以告诉信得过的大人求助，不用自己守着秘密。

如果对方打你、威胁你或逼你做不愿做的事，先找信得过的大人保护，不用先答应和好。第一个大人没回应，就找另一位。

## 给支持孩子的大人

分别听孩子说话，区分普通冲突与威胁、伤害；即使只发生一次，也应及时保护和处理。不能强迫道歉、握手或恢复亲密；遭到欺负时先保护并处理，不把责任均分当成调查。
