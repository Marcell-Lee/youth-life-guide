# 家里暂时没钱，我可以得到什么帮助

中学版｜12—17 岁

家里暂时没有钱，不是你的过错，也不需要靠停学或冒险赚钱独自解决。先说最着急的一件事，例如今天没有饭吃、缺必需用品、看病或上学有困难。

可以找班主任、学校资助负责人员，或居住地居委会、村委会，问：“哪项帮助可能适合我？谁可以协助申请？”义务教育阶段有面向家庭经济困难学生的生活补助安排；普通高中和中等职业教育也有助学金、费用减免等政策，可以问学校负责资助的老师哪些可能适用。资格和申请办法要由学校或当地教育部门核对，询问不保证一定获得。

家长无法或不愿办理、家里存在伤害，或第一位成人没有接手时，告诉另一位信得过的老师或社区工作人员，请他们继续转介，不必独自补齐所有材料。

有条件上网时，可以请可信任的大人协助查看[教育部学生资助政策查询页](https://zwfw.moe.gov.cn/zczx/)，按就读学段、学校所在地等找线索，再向学校资助人员或当地教育部门核对当年的具体规定。网页可能打不开或不完整；没有手机、不会查询，也可以直接找老师或工作人员帮助，不用等查到网页才求助。

先说眼下最需要解决的一件事，比如今天的饭、上学用品或看病。可以问接手的人下一步怎样安排，不用自己想办法赚钱填补。

## 给支持孩子的大人

先处理缺食和失去照护等急迫需要，再协助核实当地教育、医疗和救助条件。成人协调材料、转介和隐私，不承诺统一金额或到账时间，不公开比较贫困程度。
