# 想学技能，能先怎么试

小学版｜6—11 岁

想学一项技能，先选个小任务，比如画一张图或编一段故事。看看手边有什么，哪一步会做，哪一步需要人教。

能自己做的先试试，卡住了再问一个具体问题。做过以后想想，是想继续练，还是换个方法？不用先买全套设备，也不借钱或交账号换课程。

听到“交钱就能进好学校”，先别付钱或交证件，请老师或家长通过学校、当地教育部门的官方渠道核对。

涉及火、刀具、电、化学品或机器，要先有能指导的大人确认安全。不会就先不操作，不照视频独自模仿。

## 给支持孩子的大人

先核实课程内容与总费用，提供适龄任务和材料，成人负责工具及环境安全。不得把技能探索变成强制兼职或超负担家务，也不以成果排名施压。
