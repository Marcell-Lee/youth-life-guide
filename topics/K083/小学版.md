# 我跟着别人伤害了同学，怎么办

小学版｜6—11 岁

如果你跟着别人叫同学难听的名字，或者抢了他的东西，能安全做到时，可以先停下。你可以去找信得过的老师说：“我刚才跟着别人一起做了这件事，请帮我处理。”说不清也可以先说：“我需要帮忙。”

如果别人逼你继续，或你害怕离开他们，也告诉信得过的大人；不用一个人和他们争辩。第一位大人没帮忙，或者让你害怕，可以再找另一位老师、工作人员或照护者。

如果有人受伤或现在不安全，马上找能帮忙的大人。如果没有大人能及时帮忙，在中国大陆，能安全打电话时，遇到正在发生的伤害或即时人身威胁可以拨 110；有紧急医疗需要可以拨 120。没有电话时，能安全做到时，请附近的人帮忙拨打；不要为了找电话进入危险处。

## 接下来

请大人先帮助受到伤害的人，再一起想怎么补救。对方不想见你、暂时不想听你说话，你要尊重；不追着他要求原谅。你不需要当众骂自己，才能证明你想改。

想补救时，先分清自己做过什么、怎样停止继续造成影响，再提出一件做得到的补救。对方是否愿意见面和接受，要尊重他的选择。

## 给支持孩子的大人

立即制止伤害并保护受影响的孩子，分别听取事情经过，不强迫现场见面、道歉或和好。帮助孩子停止具体行为并学习承担责任，不公开羞辱或贴永久标签；也照顾因胁迫、伤害或家庭不安全而需要支持的孩子。由成人负责后续保护和跟进。
